# 이력서 PDF 작성법 (양식 스펙 — 제제미미.pdf 분석 기반)

> 업로드된 PDF를 `pdftoppm`으로 이미지 변환 + `pdfinfo`/`pdffonts`로 메타데이터 확인해서 역산한 스펙. 새 PDF 작성 시 이 스펙을 기본값으로 사용.

## 페이지/생성 도구
- 페이지 크기: A4 (595.304 × 841.89 pts)
- 생성 경로: HTML/마크다운 → LibreOffice(Writer)로 PDF 변환 (Producer: LibreOffice 24.2)
- 분량: 2페이지 기준 레이아웃(경력 5개 회사 + AI 활용 경험 + 외부 활동 + 학력)

## 폰트
- 본문/제목 모두 **Noto Sans CJK 계열** 사용(Bold/Regular 2웨이트), 영문·숫자는 DejaVu Sans 계열
- ⚠️ 실제 임베딩된 폰트가 `NotoSansCJKsc`(간체 중국어 변형)로 확인됨 — 의도한 것은 KR 변형일 가능성이 높음. **새로 만들 때는 반드시 `Noto Sans CJK KR`을 명시적으로 지정**해서 SC로 자동 치환되지 않게 할 것

## 전체 구조(위 → 아래)
1. 이름(대형 Bold) → 연락처 한 줄(LinkedIn·Medium·Portfolio·GitHub, 회색, `·`로 구분)
2. 소개문 단락(양쪽 정렬, 일반 굵기, 볼드 없음)
3. 경력 요약 줄(예: "iOS 5년+ (모바일 8년+)" — "iOS 5년+"만 볼드)
4. 얇은 회색 구분선(hr)
5. 섹션 헤더 "경력"(Bold, 소개문보다 큰 폰트)
6. 회사 블록 반복: **회사명(Bold) + 같은 줄 우측 정렬로 기간·고용형태·직무**, 그 아래 회색 서브타이틀 줄(도메인 설명), 그 아래 `•` 불릿 리스트(키워드/수치만 볼드), 마지막 줄에 스킬 태그(플레인 텍스트, 공백 구분 — **pill/box 스타일 아님**)
7. 회사 블록 사이는 별도 구분선 없이 여백만으로 구분(구분선은 "경력"/"AI 활용 경험"/"외부 활동"/"학력" 같은 대분류 섹션 앞에만 사용)
8. 학력은 마지막, 학교명 Bold + 기간/전공은 회색 소형 텍스트

## 색상
- 본문: 검정
- 서브타이틀(회사 설명, 기간·학력 메타정보): 회색
- 구분선: 옅은 회색 hr

## 불릿/강조 규칙
- `•` 불릿, 핵심 키워드·기술명·수치만 볼드, 조사/동사는 볼드 제외
- 스킬 태그 줄은 볼드 없이 플레인 텍스트, 항목 사이 공백만(쉼표·구분선 없음)

## 적용 시 체크리스트
- weasyprint/wkhtmltopdf로 만들 경우 `@page { size: A4; }` + 위 폰트 스택을 CSS에 명시
- 태그를 pill 스타일로 할지 이 PDF처럼 플레인 텍스트로 할지는 지원사 스타일에 맞춰 선택(플레인 텍스트 쪽이 더 가벼운 인상, pill은 더 캐주얼/스타트업 인상)
- 최종 산출 전 반드시 `pdftoppm`으로 재변환해 육안 검수(줄바꿈 시 한글 음절 쪼개짐 등 확인)
- 한 쪽만 고치고 끝내지 않기 — 마크다운 원본과 PDF 소스(HTML) 두 곳에 항상 동일한 문구 반영

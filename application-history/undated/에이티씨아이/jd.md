- Source: Wanted https://www.wanted.co.kr/wd/359767
- Deadline: 상시채용 (명시된 마감 없음)
- Location: 서울 금천구 가산디지털1로 171
- Employment: 정규직
- Suggested base: ② RN
- Pre-screen signals: 2/3: RN 모바일 엔지니어, 구조 설계; 경력요건 불명확, 가산

## 주요업무
React Native 기반 CollabOps Mobile 앱 개발
기존 Next.js Web 서비스를 모바일 환경에 맞게 재구성
Web / Desktop / Mobile 간 공통으로 활용 가능한 UI, 상태, 비즈니스 로직 구조 설계
공통 디자인 시스템을 기반으로 Cross-platform UI 아키텍처 구축
모바일 환경에 최적화된 인증, API 연동, 알림, 실시간 상태 업데이트 기능 개발
Zustand, TanStack Query 기반의 상태 관리 및 서버 상태 관리 구조 설계
React Hook Form, Zod 기반의 안정적인 입력 폼 및 검증 로직 구현
모바일 앱의 성능, 사용성, 안정성 개선
Cursor, Copilot 등 AI 기반 개발 도구를 활용한 빠른 개발 및 코드 품질 개선
사용자 피드백을 바탕으로 빠르게 기능을 개선하고 실서비스에 반영

## 자격요건
React Native 기반 모바일 앱을 실서비스 수준으로 개발해본 경험이 있으신 분
TypeScript 기반으로 안정적인 React Native 코드베이스를 작성할 수 있으신 분
iOS / Android 모바일 환경의 차이를 이해하고, 플랫폼별 UX와 기술 제약을 고려해 개발할 수 있으신 분
화면, 네비게이션, 상태 관리, API 연동까지 모바일 앱의 핵심 흐름을 주도적으로 설계하고 구현할 수 있으신 분
REST API 연동, 인증 처리, 비동기 데이터 관리에 대한 실무 경험이 있으신 분
Zustand, TanStack Query 등을 활용해 클라이언트 상태와 서버 상태를 체계적으로 관리해본 경험이 있으신 분
재사용 가능한 컴포넌트 구조와 확장 가능한 모바일 UI 아키텍처를 고민하며 개발할 수 있으신 분
React Hook Form, Zod 등을 활용해 폼 입력, 검증, 에러 처리, 사용자 피드백 흐름을 구현해본 경험이 있으신 분
모바일 앱의 성능, 사용성, 안정성을 고려해 문제를 발견하고 개선할 수 있으신 분
단순 페이지 구현이 아니라, 하나의 제품 경험을 모바일 환경에서 어떻게 완성할지 함께 고민할 수 있으신 분
빠른 실서비스 릴리즈와 사용자 피드백 기반 개선 사이클에 익숙하거나 이를 선호하시는 분

## 주요업무
• 학습 앱 기능을 기획과 함께 정하기: 어떤 문제를 풀지, 화면 흐름은 어떻게 할지, 무엇을 먼저 할지
• AI 도구(Claude Code 등)와 함께 빠르게 만들고 출시하기 (React Native · Expo, iOS · Android)
• 출시 후 데이터와 사용자 반응을 보고 UI/UX를 다시 설계하기
• 인앱결제, 푸시, 소셜 로그인, 스토어 배포 등 앱 기반 기능 운영

■ 합류하면 첫 90일
• 30일: 앱 구조와 배포 과정을 익히고, 작은 개선 하나를 직접 출시해요
• 60일: 처음 시작이나 다시 돌아옴 흐름 중 하나를 맡아 개선하고, 출시 전후를 비교해요
• 90일: 푸시·결제·스토어 배포 중 하나를 혼자 책임질 수 있게 돼요

■ 사용하는 기술
TypeScript, React Native, Expo, expo-router, Reanimated, Sentry / 웹: Next.js, Supabase, Cloudflare

## 자격요건
• 앱 개발 경력 3년 이상 (React Native 실서비스 경험)
• 기능을 직접 기획해서 출시하고, 결과를 보고 다시 고쳐본 경험
• AI 코딩 도구를 실무의 기본 도구로 써왔고, 그 결과물을 어떻게 검증했는지 설명할 수 있는 분
• 화면 하나를 두고 "왜 이렇게 해야 하는지"를 말로 설명할 수 있는 분

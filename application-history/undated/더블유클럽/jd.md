## 주요업무
이 포지션은 이렇게 일합니다.

• AI(Claude Code, Codex 등)로 빠르게 만들고, 사람이 검수해 실서비스에 안전하게 올리는 자리입니다.
• 서버만 보는 자리가 아닙니다. 앱, 서버, 관리자 화면이 맞물려 돌아가도록 끝까지 책임집니다.
• 연차나 직함보다, 결정된 것을 실서비스에 올리는 속도와 정확성으로 평가합니다.
• 대표 직속입니다. 맡을 범위는 면접에서 자세히 안내합니다.

[주요업무]
• 앱: React Native 앱 기능 개발과 개선, 앱스토어와 구글플레이 배포, 심사 대응, 코드 푸시(OTA) 업데이트, 구버전 앱 호환 관리
• 서버: API 설계와 개발, DB 스키마 변경과 마이그레이션, 인증과 권한, 결제 연동
• 관리자 화면과 웹: Next.js 기반 개발
• AI가 만든 코드 검수와 보완, 실서비스 배포
• 배포, 롤백, 장애 대응, 오류와 크래시 모니터링
• 개인정보와 결제 등 민감 영역의 보안
• 테스트, CI/CD, 운영 문서화

[기술스택]
• 앱: React Native
• 서버: Node.js (NestJS, Express), TypeScript, MongoDB, Redis
• 관리자 화면과 웹: Next.js (React)

## 자격요건
[자격요건]
• 실서비스 개발과 운영 경력 3년 이상 (연차보다 결과물로 판단합니다)
• 앱(React Native)과 서버(Node.js) 중 한쪽은 실무 3년 이상, 다른 한쪽은 실서비스에서 직접 다뤄 본 경험
• React Native 앱을 스토어에 배포하거나 업데이트해 본 경험
• 앱과 서버를 함께 바꿀 때 구버전 앱이 깨지지 않게 배포해 본 경험
• AI(Claude Code, Codex 등)가 만든 코드를 검수해 실서비스에 올려 본 경험
• 배포, 롤백, 장애 대응을 스스로 해 본 경험
• 문제를 스스로 정의하고 끝까지 해결하며, 막히면 바로 말하는 분

[지원 방법]
• 이력서
• 직접 출시하거나 운영한 앱 또는 서비스 링크
• AI가 만든 결과물을 실서비스로 올린 사례 1개 (5줄 이내)
• 운영 중 장애를 해결한 경험 1가지
• 다음 중 실서비스에서 직접 써 본 것을 적어 주세요: React Native, NestJS, Express, MongoDB, Redis, Next.js

## 우대사항
• 코드 푸시(OTA) 업데이트를 운영해 본 경험
• MongoDB, Redis 운영 경험
• 인앱결제, PG 결제, 본인인증 연동 경험
• 테스트 자동화, CI/CD, 오류 모니터링 도구 구축 경험
• 개인정보 보호 점검이나 보안 감사 대응 경험
• 적은 인원으로 서비스를 운영해 본 경험
